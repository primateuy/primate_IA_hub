# arranque entero. Nos pasó: teníamos `cryptography>=42.0` y el build murió con
#
#     AttributeError: module 'lib' has no attribute 'GEN_EMAIL'
#     Failed to load server-wide module `base`
#
# porque el requirements de Odoo 19 dice, textual:
#
#     cryptography==42.0.8 ; python_version >= '3.12'
#     pyopenssl==24.1.0    ; python_version >= '3.12'
#         # pinned for compatibility with cryptography==42.0.8
#
# pip resolvió nuestro `>=` a una cryptography posterior y el pyOpenSSL del
# sistema quedó llamando símbolos que ya no existen. Ni `base` ni `web` cargan.
#
# Si necesitás una versión concreta de algo que Odoo ya trae, NO lo agregues acá:
# verificá primero contra `odoo/requirements.txt` de la versión que corresponda.
