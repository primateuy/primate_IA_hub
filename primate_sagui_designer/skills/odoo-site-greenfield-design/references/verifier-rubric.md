# Verifier rubric — visual review of a generated Odoo site

You are reviewing screenshots (375 / 768 / 1440 px, full page) of a website generated by
another model, together with the design plan it was supposed to follow. You did NOT build it.
Be specific and adversarial. Output ONLY findings in this format; if everything passes, say so.

```
[FAIL|WARN] <rubric id> — <section> @ <breakpoint>
  seen: <what is wrong, concretely>
  fix:  <smallest change; name the token or element>
```

Not accepted: "improve the design", "make it more modern", "looks generic" without pointing at
the concrete element that makes it so.

## A. Fidelity to the plan
- A1 Palette roles match the plan (bg is bg, accent is accent — accent did not become page bg).
- A2 Type faces and scale match the plan (display face visible in hero; body face readable).
- A3 Section order and light/dark rhythm follow the plan.
- A4 The signature element exists and is the most memorable thing on the page.

## B. Craft
- B1 Contrast ≥ 4.5:1 for all text against its actual background, per section (check header).
- B2 Consistent spacing between sections (no double gaps, no collapsed seams).
- B3 Alignment: text blocks, images and buttons share a grid; nothing floats.
- B4 Image treatment: cropped for the slot, no stretched/letterboxed images, no stock placeholders.
- B5 Buttons: consistent style, real labels, visible on hover/focus.
- B6 Mobile: no horizontal overflow, headings wrap sanely, nav collapses, CTA reachable.

## C. Genericness (the "AI-made" tells)
- C1 Any vetoed default present (cream+serif+terracotta, black+acid green, broadsheet hairlines,
  purple gradients, emoji icons, decorative 01/02/03, invented testimonials)?
- C2 Hero is the template answer (centered headline + subtext + two buttons + stat row)?
- C3 Would a competitor's site in the same rubro look the same? Name what makes it interchangeable.
- C4 Copy: filler phrases ("Bienvenidos", "soluciones integrales", "comprometidos con la
  excelencia"), vague CTAs ("Enviar", "Más info").

## D. Odoo function (from screenshots and, if given, the DOM)
- D1 Header shows the design's nav items, not Home/Contact Us demo; readable on its bar.
- D2 Footer is the design's, not the demo footer (no info@yourcompany, +1 555, demo socials).
- D3 Real logo present.
- D4 Admin edit bar visible in the logged-in capture (page uses website.layout).

Score each block A–D as pass/fail. The site is "listo" only when A, B and D pass and C has no
FAIL (WARN in C is reported to the human as art-direction notes).
