# Anti-patterns — why each one reads as templated, and what to do instead

| Tell | Why it reads as AI/template | Do instead |
|---|---|---|
| Cream bg + serif display + terracotta accent | The current AI default; appears regardless of subject | Derive palette from the subject's physical world (materials, environment, product colors) |
| Near-black + one acid green/vermilion | Second AI default; "tech" look applied to anything | Dark is fine; pick the accent from the brand or subject, and give it a role, not a spotlight |
| Broadsheet: hairlines, zero radius, dense columns | Third default; borrows "editorial" without editorial content | Use only if the content is truly text-dense and the brief says so |
| Purple/pink/blue-violet gradients | The single strongest "generated" signal | Flat color blocks with one accent; gradients only if derived from a real material (sky, metal) |
| Centered hero + 2 buttons + stat row | Statistically the most common hero; says nothing about the subject | Open with the most characteristic thing: a real photo treatment, a strong typographic line, a live element |
| 3 icon cards "Nuestros servicios" | Interchangeable across every rubro | Show services in the form they actually take: a list with real specifics, a photo per service, a process if it is one |
| Decorative 01/02/03 numbering | Structure that encodes nothing | Number only real sequences; otherwise use eyebrows that name the content |
| Emoji as icons | Inconsistent rendering, informal, screams no-design | Lucide/Heroicons SVG, single stroke weight |
| Stock photos unrelated to the subject | Breaks trust; generic imagery = generic company | Real photos; if none, ask for them or use typographic/color composition instead of fake imagery |
| Invented testimonials / stats | Ethically wrong and immediately obvious | Omit the section, or use real material supplied by the client |
| Same font for display and body (Inter/Roboto everywhere) | No personality | Deliberate pairing; display face used with restraint |
| Every section with a big shadowed card | "Bootstrap template" feel | Let surfaces and spacing do the work; cards only where content is card-like |
| Filler copy ("Bienvenidos", "soluciones integrales") | Reads as placeholder | Specific verbs and nouns from the subject's vocabulary |
| Scattered animations (fade-in on every block) | Motion as decoration | One orchestrated moment, or none |
