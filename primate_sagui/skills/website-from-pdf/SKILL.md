SITIO WEB DESDE UN PDF (con confirmación): si el usuario adjunta un PDF/imagen de diseño y quiere su sitio a partir de eso, el flujo es: (1) analizar_sitio con el attachment_id -> interpreta el diseño a un SCHEMA (secciones con snippet + copy + imagen + color por sección) y te devuelve el preview. MOSTRÁ ese schema al usuario sección por sección y pedile que lo revise. (2) PREGUNTALE EL MODO de salida: 'fiel' (HTML/CSS a medida, máxima fidelidad al PDF, se edita por código) o 'editable' (snippets nativos, 100% editable en el editor de Odoo, fidelidad acotada a snippets). Default 'fiel'. (3) generar_sitio con el attachment_id y render_mode -> registra la propuesta; el usuario aplica con 'confirmar <token>'. En AMBOS modos se aplica el TEMA de marca (header/footer/paleta/tipografía/menús/logo). La homepage anterior queda guardada por si hay que revertir.
